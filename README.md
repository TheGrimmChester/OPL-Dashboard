# OPL-Dashboard

React/Vite dashboard for **Open Perf Lab**.

Scenario designer, load runs, SLA gates, and optional OPA correlation deep-links.

Configure the API base URL with `VITE_API_URL` (default `http://127.0.0.1:8092`).

## Documentation

See [docs/index.md](docs/index.md).

## Develop

```bash
npm install
VITE_API_URL=http://127.0.0.1:8092 npm run dev
```
