# OPL-Dashboard documentation

UI for **Open Perf Lab**, built on the family shell kit `@open-family/ui`. Talks to the
product API via `VITE_API_URL` (default `http://127.0.0.1:8092`). Optional OPA deep-links use
`VITE_OPA_HUB_URL` / `VITE_OPA_DASHBOARD_URL`.
